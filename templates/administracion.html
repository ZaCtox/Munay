Productos

En dicha pestaña podrás visualizar los datos de los productos que ya se encuentren ingresados en la base de datos, además de poder agregar nuevos productos.

Para facilitar la gestión de productos, podrás aumentar y disminuir el stock de cada producto, editar los demas datos y eliminar los productos que ya no quieras vender

Información de Inicio

Con la finalidad de tener un inicio más llamativo para los clientes, podrás editar el inicio para poner ofertas, productos especiales de fechas festivas como Navidad o San Valentín.

Desde el título, imagenes y mensajes para despertar aún más el interés de sus clientes

Contabilidad

Aquí podrás ver los datos de los Clientes, Proveedores, Ventas, Gastos, Estadística sobre las ventas y gastos y lista de Productos Vendidos. Además de administrar cada tabla de datos agregando o eliminado
